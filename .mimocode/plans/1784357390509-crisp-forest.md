# Plan: Read Version from PHP define() Constant

## Current Behavior
`getPluginMetadata()` reads version from:
1. PHP plugin header comment (`* Version: X.X.X`) - regex
2. README.txt stable tag (`Stable tag: X.X.X`) - regex

Has static fallback of `1.0.0` if regex fails.

## Change
Read version directly from PHP `define()` constant:
- `ts-team-member/class-ts-team.php`: `define( 'TSTEAM_VERSION', '1.2.9' );`
- `ts-review-showcase/class-ts-review-showcase.php`: `define( 'TSREVIEW_VERSION', '1.0.2' );`

This is the actual runtime constant used by the plugin - single source of truth.

## Files to Modify
1. `ts-team-member/build-svn.js` - `getPluginMetadata()` function
2. `ts-review-showcase/build-svn.js` - `getPluginMetadata()` function

## Implementation
Replace regex comment matching with:

```js
const defineMatch = pluginContent.match(/define\s*\(\s*['"]\w+_VERSION['"]\s*,\s*['"]([0-9.]+)['"]\s*\)/);
if (defineMatch && defineMatch[1]) {
  metadata.version = defineMatch[1];
} else {
  throw new Error('Could not read version from PHP define() constant');
}
```

Remove the static `1.0.0` fallback - throw error instead.

## Verification
- Run `npm run dist:push --dry-run` in both plugins
- Confirm correct version appears in output (1.2.9 / 1.0.2)
